# 🌍 CrisisConnect — Real-Time Disaster Alert System

## 📌 Overview
CrisisConnect is a real-time disaster alert platform that delivers live alerts to users based on proximity, severity, and disaster type.

## 🧠 Features
- 🔴 Real-time disaster alerts
- 📍 Location-based filtering
- ⚡ WebSocket-powered live updates
- 📊 Continuous data ingestion from multiple sources

## 🛠 Tech Stack
- **Backend:** Kotlin (Ktor)
- **Database:** PostgreSQL (Supabase)
- **Realtime:** WebSockets
- **Frontend:** Android (Kotlin)

## ⚙️ System Design
- Event-driven backend for live updates
- Scalable API architecture
- Continuous data pipeline for disaster ingestion
